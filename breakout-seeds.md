# Breakout Seeds

Tiny experiments for days when the production lanes have had enough of us.

## 01 — Constraint Roulette
Pick three random constraints and build something useful anyway.

Examples:
- one HTML file only
- no frameworks
- under 100 lines of JavaScript
- offline-first
- keyboard-only interaction
- no database
- usable in five minutes

## 02 — Failure Museum
Collect tiny examples of bugs that taught something useful:

- race conditions
- stale state
- auth mistakes
- weird browser behavior
- bad assumptions
- "works on my machine" classics

Each entry should answer:

> What broke? Why? What rule did we learn?

## 03 — One-Hour Tool
Build one tool in one hour that solves one annoying problem.

No roadmap. No product strategy. No investor deck. Just a tool.

## 04 — Reverse Spec
Start with a weird interface and write the specification *after* it works.

Then compare the real implementation against the spec and see what the prototype taught you.

## 05 — Local-First Everything
Take a normally server-backed idea and ask:

> How far can this go with just the browser, local storage, files, and export/import?

## 06 — Agent vs Human
Give an AI agent a bounded coding task, then review the result like a hostile maintainer.

Record:
- what the agent did well
- what it assumed
- what a human caught
- what should become an automated check next time

## 07 — Bad Idea Friday
Build one intentionally ridiculous idea seriously enough that it becomes useful.

That is probably how half the good tools start anyway.
